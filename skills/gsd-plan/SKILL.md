# GSD Phase Planning

Break down a project phase into atomic tasks with measurable acceptance criteria.

1. Read `.planning/ROADMAP.md` and `.planning/REQUIREMENTS.md`.
2. Break the phase down into 2-5 atomic tasks. Each task must fit within a single context window.
3. Define exact verification criteria for each task (tests, typecheck, UI verification).
4. Save the plan to `.planning/phases/phase-X.md`.
